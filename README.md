# Gaia — proposta de IA pessoal centrada na pessoa

Esta é uma proposta conceitual sobre uma IA pessoal, evolutiva, acessível, eficiente e protetiva. O documento registra a visão e os requisitos declarados pelo proponente; não afirma validação independente dos resultados relatados nem certificação legal de autoria ou anterioridade.

Leia a [proposta completa](PROPOSTA.md).

## Publicação e versões

Este repositório mantém uma cópia pública versionada da proposta. Para obter uma referência persistente com DOI, conecte o repositório ao Zenodo, habilite a integração e publique uma release do GitHub. O DOI só é emitido depois que o depósito é publicado no Zenodo.
